# MK - Website

My personal website built with [Hugo](https://gohugo.io/) and [Hugo Academic CV (Hugo Blox)](https://hugoblox.com/templates/) theme. It has a Portuguese and an English version, and it is hosted in GitHub Pages.

# Using:

- **[Hugo](https://gohugo.io/)** `v0.136.5` 
- **[Hugo Blox Builder](https://hugoblox.com/)** 
- **[Tailwind CSS](https://tailwindcss.com/)** 
- **[Pagefind](https://pagefind.app/)** 
- **[Netlify](https://www.netlify.com/)**
